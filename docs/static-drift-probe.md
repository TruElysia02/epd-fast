# 静态颜色与驱动历史探针

2026-10-30。用户观察到稳定尾补减轻了部分残影，但动过后停住的黑白区域仍逐渐发灰；关闭 20 秒净脉冲维护没有明确改善。此探针用于区分短驱动返回后的颜色差异与后续继续运行的影响，没有光学检测。

## 图案与过程

上下两排的最终目标分别为白、黑；每排左侧为 `REF`，右侧为 `RETURN`：

| 位置 | 过程 |
| --- | --- |
| 左侧 `REF` | 从全刷参考开始，不施加显式黑白驱动 |
| 右侧 `RETURN` | 只对交替的 8×8 小格，连续反色驱动 13 次，再连续反向返回 13 次；相邻小格保持参考色 |

右侧每排测试区域为 64×24 像素，12 个小格实际接受驱动，每方向两排共 1536 个像素。若端态相同，最终应该看不到棋盘格；实际可能仍有颜色或纹理差异。13 次连续脉冲只是受控历史，不等价于视频的“11 次普通预算、等待稳定、再补 2 次”时序。

往返结束发送一轮全保持，先保持模拟电源开启、无扫描 3 秒，再进入下列阶段：

- `drift hold`：1500 次零掩码保持扫描，调度周期 12.5ms，名义 18.75 秒。
- `drift idle`：关闭模拟升压，静置 18.75 秒，不扫描。

两组都从同一全刷参考重新开始。扫描组在第 500、1000、1500 次输出检查点，实际阶段时长由 `DRIFT_RESULT sample_wall_us` 记录；最后一次扫描结束时可能比静置组略早。`total_activations` 统计探针中的快刷扫描，不包含初始全刷及供电控制；两组分别为 1527 和 27，均低于 2000 次，结束关闭升压并保留图案，不在阶段之间全刷或重新准备。

命令要求 FR5 与全部 gate。探针直接使用既有画布与黑白掩码，不增加逐像素数组、不更换电压或波形参数。两个阶段由主循环推进，每次保持扫描同步完成后才处理下一条串口命令；`status` 可随时读取，其他改变命令会先取消探针并关电。探针期间不执行动画维护或定期全刷。结束后发送 `apple loop` 会按正常流程重新全刷并重置模型，再恢复播放。

## 观察范围

右侧在往返结束时已经存在棋盘格，说明这段短驱动没有复现相邻全刷参考的同色端态；不能把已有差异全部算作后续保持扫描造成。若起初接近、扫描时差异逐渐增大，再用关电静置组比较，才能进一步判断继续运行的影响。两组都不复现也不能排除视频中的频繁反向、相邻像素驱动等条件。

“保持”是逻辑波形状态，不能仅凭零掩码证明像素上的实际电场为零。此探针不直接测量粒子位置、电压或反射率。

## 首轮执行

两个固件环境均构建通过。实机先执行 `drift idle` 后立即 `stop`，确认取消结果为 `canceled=1`，正常全刷停机、无遗留扫描故障。随后重新开始正式 `drift hold`：1500 次保持扫描全部完成，累计忙时 12,024,907μs，实际扫描阶段 18,746,462μs，总激活 1527 次。结束时 `running=0 fault=0 analog=0 drift=0`，保留诊断图案供观察。

此结果只验证数字执行与收尾，棋盘纹理出现的时机及灰差仍待用户观察；关电静置的完整对照尚未执行。[首轮原始记录](../measurements/static-drift-probe.json)
