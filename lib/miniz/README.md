# Host inflate test dependency

miniz_tinfl.c, miniz_tinfl.h and miniz_common.h come from
https://github.com/richgel999/miniz/tree/2948eebafc5b9f1c69bebed80333e403a09bd62d
under the included MIT license.

Only changes: miniz_tinfl.c includes miniz_tinfl.h instead of the full miniz.h,
and is wrapped in !ESP_PLATFORM so firmware uses the ESP32-C6 ROM inflater.
miniz_export.h supplies the empty export annotation normally generated by CMake.
This host copy is used to verify the BAZ9 video format without an ESP32 device.
